Import from your pipeline

What can be imported

The Import button reads three kinds of file into the record you are editing.

A BIDS sidecar such as sub-01_task-x_eeg.json or _meg.json. Sampling rate, reference and recording filters are read.

An OSL preprocessing config (.yml). Filter cutoffs, Maxwell filtering, bad-channel detection, ICA and re-referencing are read.

A summary of an MNE-Python file, written with these lines:

import json, mne
raw = mne.io.read_raw_fif("your_preprocessed_raw.fif")
i = raw.info
json.dump({"source": "mne", "sfreq": i["sfreq"],
  "highpass": i["highpass"], "lowpass": i["lowpass"],
  "bads": i["bads"], "projs": [p["desc"] for p in i["projs"]],
  "custom_ref_applied": int(i["custom_ref_applied"]),
  "maxfilter": bool(i.get("proc_history"))},
  open("pipeline_mne.json", "w"))

Imported values are rounded to the nearest option on the map. The exact numbers go into the value fields.

What others chose

Load several records, for example the coded pipelines of a many-analyst study. Branch width then shows how often each option was chosen. Frequency describes practice and is not a recommendation.
