# pipeline-map

An interactive map for declaring an EEG or fMRI processing path.
Each processing step is a node, nodes are grouped by stage, and a
study's chosen path is highlighted across the map.

Live site: https://yufang-yang.com/pipeline-map/

## Use

Open the live site, or open index.html in a browser.
Click a node to unfold its options.

## Contributing

The map will open to contributions after its first presentation.
Issues with suggested steps are welcome.
